# Smart Retail Intelligence — 2026 UI
Clean, modern React/Vite prototype for the camera-free SIH concept.

## Run
npm install
npm run dev

### Included
Dashboard, Live Store, Products, Inventory, Stock Orders, Transactions, Retail Guardian, AI Insights, Notifications and Settings.

### Functional in prototype
- Add Product modal
- New Stock Order modal
- Mark order as received
- Receiving stock automatically updates inventory
- Product search
- Product removal
- Live trolley selection
